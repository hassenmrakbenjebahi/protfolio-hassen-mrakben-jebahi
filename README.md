# Portfolio — Hassen Mrakben Jebahi

Static site (plain HTML/CSS/JS, no build step).

- `index.html` — the whole site
- `assets/photo.jpg` — portrait
- `assets/Hassen_Mrakben_Jebahi_CV.pdf` — CV download (replace the file to update it)

## Deploy
**GitHub Pages:** push to a repo, then Settings → Pages → Deploy from branch → `main` / root.
(Name the repo `hassenmrakbenjebahi.github.io` for a root URL.)
**Vercel / Netlify:** import the repo, framework "Other", no build command, output directory `/`.
